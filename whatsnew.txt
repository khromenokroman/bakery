Журнал изменений bakery
----------------------------------------------------------------------------------------------------
[+] 0.5.0.0.2026-10-11 docs - перепроведение: проведённый документ правится и сохраняется одной транзакцией, минус проверяется только по итогу; кнопки документа и рецептуры вверху, панель документа прилипает к верху окна;
[+] 0.4.0.0.2026-10-11 stock - поступление из производства с заполнением по заявкам, проведение и отмена проведения, остатки на дату с запретом минуса на конец любого дня; API /api/docs/{id}/post, /unpost, /api/stock; сценарии с кликами в CI;
[-] 0.3.2.0.2026-10-11 web - страницы снова открываются: исправлена бесконечная рекурсия render() из 0.3.1.0 («Maximum call stack size exceeded»); проверка страниц в headless-браузере в CI;
[-] 0.3.1.0.2026-10-11 web - на страницах не выводится текст «null»: был под пустым списком заявок и в расчёте потребности без предупреждений;
[+] 0.3.0.0.2026-10-11 orders - заявки на производство по датам и расчёт потребности: продукция, полуфабрикаты и сырьё через многоуровневые рецептуры с однократным округлением вверх, печать расчёта; API /api/docs и /api/requirements;
[+] 0.2.0.0.2026-10-11 catalog - номенклатура (сырьё, полуфабрикаты, продукция в кг, л или шт) и многоуровневые рецептуры с проверкой циклов: API /api/items и страницы веб-интерфейса;
[+] 0.1.0.0.2026-10-11 bakery - каркас: HTTP-сервер на cpp-httplib (header-only), база SQLite с миграциями схемы, стартовая страница веб-интерфейса, сборка DEB, CI;
